# Aiqaramba Homebrew Tap

Homebrew tap for [Aiqaramba](https://aiqaramba.com) command-line tools.

## Install

```sh
brew install alex-ai-eu/tap/aiqa
```

## Contents

- **aiqa** — command-line client for the Aiqaramba QA platform API.
  Run `aiqa --help` for usage; every API endpoint is available as a
  subcommand with full documentation built in.

Casks in this repository are generated and pushed automatically by
[GoReleaser](https://goreleaser.com) when a new version is released.
Do not edit them by hand.
